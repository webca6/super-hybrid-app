# Tiggo 8 Super Hybrid App

Chery Tiggo 8 Super Hybrid companion app — final Home Screen version. Plug-in hybrid, not fully electric. Australian figures: 95 km EV max (NEDC), 1,200 km total max, 18.4 kWh battery, 60 L fuel tank.

Open index.html in Safari on iPhone and use Share → Add to Home Screen.
